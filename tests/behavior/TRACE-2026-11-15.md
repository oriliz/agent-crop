## 4. Agent 做了什么

它没有绑定就开始侦察——但对照它真正收到的任务（开源维护），它的行为其实是自洽的：它在盘仓库、看有没有 CI。**是测试喂错了任务，不是它没守协议。**

## 结论：这轮无效，原因不是 AI，是测试环境

同一个 `DSH_HOME` 下，**排队消息和注记是跨会话共享的**。只隔离 profile 和数据目录不够。

要拿到干净的真实实例行为，必须隔离整个宿主状态：

```bash
export DSH_HOME=~/.dsh-e2e        # 独立 home：配置、profile、凭证、队列全部独立
dsh plugin --profile lab add ~/.agentcrop/current
DEEPSEEK_API_KEY=... KIT_DATA_DIR=... dsh --profile lab "继续吧"
```

并且每轮跑之前要**校验注入文本**：

- 用户消息 == 我发的那句
- 注记里的文案 == 当前版本
- 没有 `agent/inbox/spliced` 的第三方消息

校验不过就重跑，不进报告。
